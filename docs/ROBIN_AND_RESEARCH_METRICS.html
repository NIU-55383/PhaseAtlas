Robin boundaries and research metrics

Independent implementation · 18 October 2026. Second-order bounded solver version phaseatlas-fv-sbdf2-1.1.0; research workbench version phaseatlas-research-1.1.0.

Boundary model

Each 1D endpoint or 2D rectangular edge can use Dirichlet, Neumann or passive Robin conditions. Robin means αu + β∂ₙu = g. The outward normal reverses the derivative at the left and bottom edges. Coefficients may be constant parameter expressions; α ≥ 0, β ≥ 0, and at least one is positive. The target may depend on coordinates, time and parameters. Nonlinear, time-dependent-coefficient and active boundary feedback are not implemented.

For heat exchange this represents ∂ₙu = Bi(ambient − u). The convection-cooled rod is a dimensionless example; physical prediction requires consistent scales, material parameters and measured boundary data.

For a boundary-adjacent cell value U and spacing h, solve the linear face reconstruction to obtain q = (g − αU)/(β + αh/2), u_face = (βU + hg/2)/(β + αh/2), and the ghost value U + hq. First derivatives use a quadratic reconstruction with the two nearest cell centers. This reduces exactly to the existing Dirichlet and Neumann closures. Coefficients and targets are normalized together before assembly. Positive coefficients preserve the symmetric positive-definite implicit diffusion system used by conjugate gradients.

Research workflows added

  • Boundary/bulk balance: independently recompute mass or thermal-content integrals, per-side diffusive input, other terms in the entered PDE, integrated total input and a saved-frame balance defect. Imported diagnostics are ignored. The defect includes solver error and trapezoidal quadrature error from saved times; increasing saved-frame count can change it.
  • Custom maps: choose an observable expression, spatial statistic or point probe, and final value, change, maximum, time average or first threshold event. An unseen event is missing, not zero. Temporal extrema/events can be missed between saved frames.
  • Wave and balance maps: color scans by final speed, phase shift, aligned shape RMS, weighted/local/global disturbance norms or maximum absolute balance defect. Wave settings are fixed and exported for the entire map. Baseline zero-perturbation runs can still show nonzero numerical/reference error, especially under large exponential weights.
  • Parameter sensitivity: centered secants on interior scan points and one-sided secants at endpoints. Missing neighbors leave a missing derivative. These are finite-time sampled sensitivities, not adjoint gradients, branch continuation or stability classifications.
  • Exports: full study JSON includes metric settings, missing-value reasons, sensitivity tables and computed balance audits. CSV exports preserve full numeric precision and leave missing values blank. Study import restores model, scan and metric settings but recomputes results.
