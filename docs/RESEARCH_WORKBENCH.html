PhaseAtlas research workbench

Independent implementation · 18 October 2026 · Entry point: dist/workbench.html (serve over HTTP to run module workers).

Studio passes its editable configuration to the workbench through a model link. The workbench does not auto-run links or imports. Existing solvers are reused unchanged; no VisualPDE source or assets are included.

Implemented research workflows

  • Single experiments and sequential three-level spatial or temporal studies. Spatial refinement holds the actual time step fixed. Temporal refinement holds the grid fixed. Every level is an independent solve.
  • One- and two-parameter scans with two to five values per axis, full trajectories, click-to-inspect cells, visible per-run errors, cancellation and resume of pending/canceled jobs.
  • 1D wave diagnostics: unique threshold crossings, sampled crossing speed, bounded-window translation alignment, aligned shape RMS, and global/local/exponentially weighted raw disturbance L² norms. Periodic seam crossings count toward ambiguity; constant profiles do not produce invented shifts.
  • Parameter sliders, custom observation expressions, line/plane/surface views, palettes, contours, vector overlays, point probes, spatial statistics, animation and periodic initial-data seeds.
  • Full study exports retain job configurations, statuses/errors, actual solver metadata, raw fields, observations, measurements, presentation settings and calculated wave diagnostics. Model edits never change already-computed run provenance. Study imports recover the recipe and recompute results. The three-run bundle opens in the separate Evidence viewer.

Limits that affect interpretation

Numerical order is inferred from three finite resolutions. Cell-center interpolation contributes to bounded-grid differences. Cancellation is an in-memory workflow; exporting the study preserves completed trajectories, while importing reruns the recipe. A page refresh does not persist an active queue.

Alignment uses an 81-point shift search and local refinement with linear interpolation. The window is fixed and bounded problems reserve an interpolation buffer. A reported shift is not a proof of a unique global phase. Search-limit hits and missing threshold crossings are visible. Weight choice changes the norm and admissible perturbations; it does not itself prove weighted stability.

Parameter maps are finite-time initial-value scans, not pseudo-arclength continuation or certified bifurcation diagrams. Reference formulas remain user supplied. All supported operator and boundary restrictions remain those of Studio; arbitrary PDEs are not supported.

The capability comparison records current gaps, including more fields, algebraic species, variable/cross diffusion, irregular domains, second-order Robin boundaries, image/random data, live forcing brushes, true checkpoints and GPU execution. They need separate numerical acceptance tests before being advertised.
