# PhaseAtlas visual system

The supplied T-strands Imperial Beamer template is the reference: blue and white, prominent blue headings, generous white space, and restrained geometry. PhaseAtlas uses its own name and wave mark.

| Color | Role |
|---|---|
| `#0000CD` | Primary navigation, actions, field/global-norm curves |
| `#000080` | Active navigation, secondary headings |
| `#FFFFFF` | Page, cards, space around figures |
| `#F5F5F5` | Control and equation panels |
| `#FBF7DC` | Cautions and evidence limitations |
| `#C96428` | Disturbance, local norm, positive diverging scale |
| `#8275BC` | Weighted norm and third diagnostic series |

The first five colors come from the supplied template. Orange and violet distinguish scientific quantities. The blue-white-orange diverging map places zero at white; limits stay fixed within each experiment. Labels and legends identify each series.

Typography uses Arial and Helvetica fallbacks without remote or proprietary fonts. UI, exported SVG, animation titles, Python figures, and the project brief follow the same palette. All user-facing copy and exported reports are English.
