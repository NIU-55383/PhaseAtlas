PhaseAtlas: from interactive PDEs to inspectable research

Related-work review and implementation direction · 18 October 2026

Positioning proposal: a browser workbench for reproducible nonlinear-wave experiments, connecting visual evolution, explicit numerical evidence and a precise mathematical question. This is a focused workflow, not a claim to have invented interactive PDE simulation, convergence studies or continuation.

The practical user and the first useful job

Primary users: a graduate researcher studying nonlinear waves or patterns, a collaborator reproducing a figure, and an instructor introducing numerical verification. Their first job is to determine whether a visually interesting change persists when the numerical settings change.

The delivered Evidence page accepts existing Studio exports, recomputes norms and three-level self-comparisons, replays the data, and exports the source trajectories with a report. It does not run the solver again. Imported reported errors, residuals and previous conclusions are not trusted as new evidence.

Start with a fixed-temperature cooling rod: three spatial grids, the same actual time step, and unchanged model/initial/boundary data. This has a direct engineering interpretation, but the dimensionless example is a verification case, not a calibrated predictive model. The same workflow applies to supported phase-field and wave experiments.

Connection to the original MAE03 problem

The model is u_t = γ u_xxxx − β u_xxx + α u_xx − ∂x(a u² + 2b u³/3). The corrected reference front uses γ=−1, β=−15/2, α=−71/4, a=0, b=315/16, c=105/8. Its shape is U(ξ)=(1+exp(−ξ))^(−3/2).

The far-field real dispersion at these coefficients is Re λ(k)=−k⁴+(71/4)k². Thus long waves grow in the unweighted far-field problem. A project promising ordinary unweighted asymptotic stability of that reference would be incorrectly targeted. Finite boundaries or a weighted norm can change what is observed and require their own analysis.

A defensible candidate question is: how do admissible parameter changes alter weighted/local disturbance behavior and the persistence of the travelling front, and how do finite-domain observations relate to the whole-line problem? First establish the correct solution class and existing literature. Then use continuation and independently checked numerics to locate candidate regimes, and pursue an analytic or computer-assisted result only where its hypotheses are satisfied. This is a research direction, not a claim that a new theorem has been obtained.

The platform's practical role is to make counterexamples, transitions, numerical artifacts and reproducible evidence visible. It supports the mathematical research; its interface is not itself the mathematical result.

Publication target

Nonlinearity's official scope includes theorems as well as significant ideas, conjectures and numerical or physical experiments. Its stated acceptance criterion is a significant contribution to mathematical or physical understanding. Accordingly, a substantial numerical discovery with convincing analysis may be relevant; a generic simulator plus familiar examples is a much weaker match. No acceptance or novelty is implied by this plan.

Integration and reproducibility

The addition uses new filenames only: dist/evidence.html, evidence.css, evidence.mjs, evidence-core.mjs and dist/data/evidence-demo.json. It does not edit the active Studio solver or its controls. Existing Flask static serving can serve it at /evidence.html. A navigation link can be added when the main-thread interface changes are integrated.

Run node --test tests/evidence.test.mjs. Rebuild the measured example with node research/build_evidence_demo.mjs. The browser QA uses the existing Playwright/Edge environment and runs with node tests/evidence_browser_qa.mjs; it starts and closes its own temporary local server.

For bounded grids, each adjacent-grid difference uses the same refinement ratio. The finer difference is then interpolated onto the coarsest cell-center grid. Interpolation contributes to and can limit the observed order. Three levels do not demonstrate an asymptotic regime. Small differences, low residuals and matching implementations are distinct checks, each with distinct limitations.
